## Контекст

Собранный лот нужно разложить по вкладкам stash, иначе инвентарь переполняется и бот теряет дроп следующей карты.
`src/poe2bot/stash/` пуст.

## Задача

- [ ] `stash/manager.py`: план раскладки — вкладка (Tab) и слот под каждый тип предмета.
- [ ] Приоритеты: валюта → фрагменты/ключи → базы/эссенции → уникальный лут.
- [ ] Поштучный pickup предметов из инвентаря с проверкой свободных слотов.
- [ ] Fallback при переполнении вкладки или инвентаря: оставить в инвентаре, залогировать, продолжить цикл.
- [ ] Слотовые координаты — из ROI-конфига калибровки, не хардкод.

## Инварианты

- Планировщик раскладки — чистая функция от списка предметов и карты слотов (тестируется без UI).
- Никаких прямых кликов мимо `input/mouse.py`.
